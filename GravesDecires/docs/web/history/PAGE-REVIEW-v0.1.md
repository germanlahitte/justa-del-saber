# Graves decires — Revisión editorial página por página v0.1

**Propósito:** revisión manual, página por página, del MODO LEER.
Solo contiene metadata factual precompletada (heading/sección, layout,
SourceReferences). Ninguna observación fue generada automáticamente —
completalas vos mismo debajo de cada página.

Las páginas están agrupadas **por spread** (cómo se muestran juntas en la
hoja): `Spread 1` es la portada (página 1, sola); cada `Spread N` (N ≥ 2)
agrupa las páginas `2N-2 | 2N-1` (izquierda | derecha), que son las que se
ven lado a lado en pantallas anchas.

**Cómo revisar:** navegá `http://localhost:4321/libro/p/N` para cada
página de cada spread y anotá tus observaciones en la sección correspondiente.
